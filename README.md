# QueryAgent

AI-powered data agent for exploring and analyzing PostgreSQL databases using natural language.

## Backend

- Django
- Django REST Framework
- PostgreSQL

## Frontend
- Next.js
- TypeScript
- Tailwind CSS
- shadcn/ui
- FSD-inspired lightweight structure

## Stack
- OpenAI
- Docker Compose

## Project structure

```text
querypilot/
├── frontend/
├── backend/
└── docker-compose.yml
```

## Development

docker compose up --build
